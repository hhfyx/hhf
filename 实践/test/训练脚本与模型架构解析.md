## 1. 整体流程概览

```
train_defect_generator.py 执行流程
═══════════════════════════════════════════

main()
  │
  ├─ ① 解析参数（epochs, lr, dataset_root ...）
  │
  ├─ ② 加载 SD Inpainting Pipeline（仅用 VAE）
  │
  ├─ ③ precompute_latents()
  │     对所有图片：VAE 编码 → latent → 缓存到 latents_cache.pt
  │     释放 VAE，节省显存
  │
  ├─ ④ 创建 DefectGeneratorTrainer
  │     加载 Pipeline → 设置 LoRA → 添加 <defect> token
  │
  └─ ⑤ trainer.train()
        for epoch in range(start, num_epochs):
            for each latent:
                train_step()  ← 核心训练逻辑
            save checkpoint
```

### 为什么先预计算 Latent？

```
优化前：                优化后：
每个 step:              VAE 编码一次性完成（~2分钟）
  1. VAE 编码图像          保存到 latents_cache.pt
  2. UNet 前向传播       每个 step:
  3. 反向传播                1. 直接从缓存加载 latent
→ 39 秒/step               2. UNet 前向传播
                            3. 反向传播
                          → 0.31 秒/step（加速 126 倍）
```

## 2. 基座模型架构：Stable Diffusion Inpainting

### 2.1 整体架构

### 2.2 Three Key Components

#### VAE (Variational Autoencoder)

```
功能: 图像 ↔ 潜空间 的桥梁

编码 (压缩):
  512×512×3 (RGB 图像)
      │
      ▼
  VAE Encoder (下采样 ×8)
      │
      ▼
  64×64×4 (潜空间 latent)
      │  每个像素代表 8×8 区域的语义信息
      │  4 通道 = 4 维特征向量

解码 (还原):
  64×64×4 (latent)
      │
      ▼
  VAE Decoder (上采样 ×8)
      │
      ▼
  512×512×3 (RGB 图像)

为什么用 VAE？
  • 像素空间 (512×512×3 = 786,432) → 潜空间 (64×64×4 = 16,384)
  • 压缩比 48:1，大幅降低计算量
  • Latent 空间更关注语义，忽略高频像素噪声
```

#### UNet（核心去噪网络）

```
UNet 结构（纵向）：
                   Input (9ch)
                      │
                  Conv2d(9→320)
                      │
    ┌─────────────────┼─────────────────┐
    │    DownBlock 0   │                 │
    │  320→320 (2层)   │                 │
    └────────┬────────┘                 │
             │                          │
    ┌────────▼────────┐                 │
    │    DownBlock 1   │   Skip Connect  │
    │  320→640 (2层)   │───────┐        │
    └────────┬────────┘       │        │
             │                │        │
    ┌────────▼────────┐       │        │
    │    DownBlock 2   │       │        │
    │  640→1280 (2层)  │──────┤        │
    └────────┬────────┘       │        │
             │                │        │
    ┌────────▼────────┐       │        │
    │   MiddleBlock    │       │        │
    │ 1280→1280 (1层) │       │        │
    └────────┬────────┘       │        │
             │                │        │
    ┌────────▼────────┐       │        │
    │    UpBlock 2     │       │        │
    │  1280→640 (2层)  │◄──────┤        │
    └────────┬────────┘       │        │
             │                │        │
    ┌────────▼────────┐       │        │
    │    UpBlock 1     │       │        │
    │  640→320 (2层)   │◄──────┘        │
    └────────┬────────┘                 │
             │                          │
    ┌────────▼────────┐                 │
    │    UpBlock 0     │                │
    │  320→320 (2层)   │                │
    └────────┬────────┘                 │
             ▼                          │
         Conv2d(320→4)                  │
             │                          │
         Output: 噪声预测 (4ch)          │

每个 Block 内部：
  ┌──────────────────────┐
  │   ResNetBlock ×2     │
  │   ┌──────────────┐   │
  │   │ GroupNorm     │   │
  │   │ SiLU          │   │
  │   │ Conv3×3       │   │
  │   │ Dropout       │   │
  │   └──────────────┘   │
  │                      │
  │   Transformer2D ×1   │  ← LoRA 挂载点
  │   ┌──────────────┐   │
  │   │ LayerNorm     │   │
  │   │ Self-Attention│   │  ← to_q, to_k, to_v, to_out.0
  │   │   + LoRA      │   │
  │   │ Cross-Attn    │   │  ← Text Encoder embedding 注入
  │   │   + LoRA      │   │
  │   │ FFN           │   │
  │   └──────────────┘   │
  └──────────────────────┘

Transformer2D 中的 Cross-Attention:
  Q = W_q × hidden_states          (来自图像 latent)
  K = W_k × text_embeddings        (来自 prompt)
  V = W_v × text_embeddings        (来自 prompt)
  
  Attention = softmax(Q × K^T / √d) × V
              ↑
         决定了图像每个位置"看"文本的哪个词
```

#### Text Encoder (CLIP ViT-L/14)

```
输入: "A photo of <defect>"
  │
  ▼
Tokenizer: BPE 分词
  ["A", "photo", "of", "<defect>", "<|endoftext|>", ...]
  → token IDs [49406, 3319, 539, 49409, 49407, 0, 0, ...]
  │  ↑ 49409 = 新增的 <defect> token
  │
  ▼
CLIP Text Encoder (12 层 Transformer)
  │
  ▼
输出: 77×768 的 text embedding
  │  (77 = max_length, 768 = hidden_size)
  │
  ▼
传入 UNet Cross-Attention 作为 K 和 V
```

### 2.3 9 通道输入详解

```
标准 SD (txt2img) 的 UNet 输入:      Inpainting SD 的 UNet 输入:
┌──────────────────────┐            ┌──────────────────────────┐
│  noisy_latent (4ch)  │            │  noisy_latent (4ch)      │
│                      │            │  zero_mask    (1ch)      │
│                      │            │  zero_masked  (4ch)      │
│                      │            │                          │
│  总通道: 4           │            │  总通道: 4+1+4 = 9       │
└──────────────────────┘            └──────────────────────────┘

在我们的训练中（DreamBooth 风格）:
  zero_mask    = 全 0     ← 不使用 mask 信息
  zero_masked  = 全 0     ← 不使用 masked_image 信息
  noisy_latent = 添加了噪声的 latent

为什么用 Inpainting UNet 做标准扩散训练？
  • 我们不需要 Inpainting 功能
  • 但因为 LoRA 是基于 Inpainting UNet 训练的
  • 推理时 mask 和 masked_image 填零即可
  • 相当于 "浪费" 5 个通道，但 LoRA 权重兼容
```

## 3. LoRA 低秩适配原理

### 3.1 核心公式

```
原始权重更新:          W' = W + ΔW
全参数微调:            ΔW ∈ R^(d×k)
  (参数量 = d × k，例如 d=320, k=320 → 102,400)

LoRA 低秩分解:        ΔW = A × B
  A ∈ R^(d×r), B ∈ R^(r×k), r << min(d,k)
  (参数量 = d×r + r×k = r(d+k)，例如 r=8 → 8×(320+320) = 5,120)

压缩比 = (d×k) / (r×(d+k))
  当 d=k=320, r=8: 102,400 / 5,120 = 20 倍
```

### 3.2 直观理解

```
全参数微调:
  ┌──────────────────┐
  │  原始权重 W       │  修改所有 102,400 个参数
  │  (320×320)        │  容易过拟合、存储成本高
  └──────────────────┘

LoRA (r=8):
  ┌──────────────────┐     ┌──────┐
  │  原始权重 W       │  +  │ A    │  ×  B    │
  │  (320×320)        │     │ 320×8 │ 8×320  │
  │  ═══ 冻结 ═══     │     │ 仅 5,120 个参数可训练 │
  └──────────────────┘     └──────────────────┘

  效果: W' = W_冻结 + A_训练 × B_训练
       ≈ 在原始权重的"低维流形"上微调
```

### 3.3 LoRA 配置详解

```python
unet_lora_config = LoraConfig(
    r=8,                          # LoRA 秩（rank），控制参数量
    lora_alpha=8,                 # 缩放系数，ΔW = (alpha/r) × A×B
    target_modules=[              # 挂载目标层
        "to_k",                   # Attention 的 K 投影
        "to_q",                   # Attention 的 Q 投影
        "to_v",                   # Attention 的 V 投影
        "to_out.0",              # Attention 的输出投影
    ],
    lora_dropout=0.0,            # Dropout 率（0 = 无 dropout）
)

text_encoder_lora_config = LoraConfig(
    r=8,
    lora_alpha=8,
    target_modules=[
        "k_proj", "v_proj",       # Cross-Attention 的 K/V 投影
        "q_proj", "out_proj",    # Cross-Attention 的 Q/输出投影
    ],
)
```

### 3.4 为什么 LoRA 有效

```
注意力层的本质:

  Attention(Q, K, V) = softmax(QK^T/√d)V

  Q = W_q × X    (图像特征到 Query)
  K = W_k × T    (文本特征到 Key)
  V = W_v × T    (文本特征到 Value)

LoRA 修改了 W_q, W_k, W_v, W_o:
  W_q' = W_q + A_q × B_q
  W_k' = W_k + A_k × B_k
  ...

这意味着:
  • 模型学习如何 "关注" 缺陷相关的文本概念
  • 学习图像中哪些区域对应 "缺陷" 的语义
  • 不改变底层图像生成能力，只改变注意力分布

另一个视角:
  训练前:  "A photo of <defect>" → UNet 不知道 <defect> 是什么
  训练后:  "A photo of <defect>" → UNet 的注意力指向"裂纹、破洞"区域
  
  LoRA 微调的就是这个"注意力指向"的方向
```

## 4. 训练脚本逐段解析

### 4.1 `main()` 函数

```python
def main():
    # 1. 解析参数
    args = parser.parse_args()
    
    # 2. 加载 Pipeline（仅用 VAE）
    pipe = diffusers.StableDiffusionInpaintPipeline.from_pretrained(...)
```

**关键设计**：VAE 用完就释放，因为训练只需要 latent，不需要 VAE decoder。

### 4.2 `precompute_latents()` — 速度优化的关键

```python
def precompute_latents(vae, dataset_root, image_size, device, cache_dir, scaling_factor):
    cache_path = os.path.join(cache_dir, "latents_cache.pt")
    
    # 如果缓存已存在，直接加载
    if os.path.exists(cache_path):
        data = torch.load(cache_path, map_location="cpu")
        return data
    
    # 第一次运行：遍历所有图片，VAE 编码
    for dtype, items in defect_groups.items():
        for item in items:
            # 读取图片
            img = imread_unicode(item['path'])
            img = cv2.resize(img, (image_size, image_size))
            
            # 转为 tensor [-1, 1]
            img_tensor = torch.from_numpy(img_rgb).float() / 127.5 - 1.0
            
            # VAE 编码 → latent
            latent = vae.encode(img_tensor).latent_dist.sample()
            latent = latent * scaling_factor  # 缩放
            
            # 保存到 CPU（GPU 放不下 3000+ latent）
            latents_list.append(latent.squeeze(0).cpu())
    
    # 保存缓存
    torch.save(all_latents, cache_path)
```

**`scaling_factor`**：约为 0.18215，作用是让 latent 值的标准差接近 1，匹配标准正态噪声的分布。

### 4.3 `DefectGeneratorTrainer.__init__()`

```python
class DefectGeneratorTrainer:
    def __init__(self, model_id, device="cuda", lora_rank=8):
        # 1. 加载完整 Pipeline（含 UNet + Text Encoder）
        self.pipe = StableDiffusionInpaintPipeline.from_pretrained(model_id)
        
        # 2. 提取各组件引用
        self.vae = self.pipe.vae
        self.unet = self.pipe.unet          # ← 目标：挂载 LoRA
        self.text_encoder = self.pipe.text_encoder  # ← 目标：挂载 LoRA
        self.tokenizer = self.pipe.tokenizer
        self.scheduler = self.pipe.scheduler
        
        # 3. 设置 LoRA
        self._setup_lora()
        
        # 4. 冻结 VAE（不参与训练）
        self.vae.requires_grad_(False)
        
        # 5. 启用 Gradient Checkpointing（省显存）
        self.unet.enable_gradient_checkpointing()
        
        # 6. 添加 <defect> 占位 token
        self.placeholder_token = "<defect>"
        self._add_placeholder_token()
```

### 4.4 `_setup_lora()` — LoRA 挂载

```python
def _setup_lora(self):
    from peft import LoraConfig, get_peft_model
    
    # UNet 的 LoRA（挂载到注意力层的投影矩阵）
    unet_lora_config = LoraConfig(
        r=self.lora_rank,      # 8
        target_modules=["to_k", "to_q", "to_v", "to_out.0"],
    )
    self.unet = get_peft_model(self.unet, unet_lora_config)
    
    # Text Encoder 的 LoRA
    text_encoder_lora_config = LoraConfig(
        r=self.lora_rank,
        target_modules=["k_proj", "v_proj", "q_proj", "out_proj"],
    )
    self.text_encoder = get_peft_model(self.text_encoder, text_encoder_lora_config)
```

**`get_peft_model` 做了什么**：
1. 遍历目标模块，找到 `to_k`、`to_q` 等层
2. 在每个层旁边插入 LoRA A/B 矩阵
3. 冻结原始权重，仅 LoRA 参数可训练
4. 修改 forward 函数：`output = original(x) + alpha/r × (B(A(x)))`

### 4.5 `train_step()` — 单步训练核心

```python
def train_step(self, batch):
    # 1. 获取预计算的 latent
    latents = batch['latent'].to(device, dtype=unet.dtype)  # [1, 4, 64, 64]
    
    # 2. 生成随机噪声
    noise = torch.randn_like(latents)                        # [1, 4, 64, 64]
    
    # 3. 随机采样时间步
    timesteps = torch.randint(0, 1000, (bsz,))              # 随机 [0, 1000)
    
    # 4. 前向扩散：向 latent 添加噪声
    #    x_t = √ᾱ_t × x_0 + √(1-ᾱ_t) × ε
    noisy_latents = scheduler.add_noise(latents, noise, timesteps)
    
    # 5. 获取文本嵌入
    #    "A photo of <defect>" → Text Encoder → 77×768
    text_embeddings = self.get_text_embeddings(prompt)
    
    # 6. 构造 9 通道 UNet 输入
    #    [noisy_latent, zero_mask, zero_masked]
    unet_input = torch.cat([noisy_latents, zero_mask, zero_masked], dim=1)  # [1, 9, 64, 64]
    
    # 7. UNet 前向：预测噪声
    noise_pred = self.unet(unet_input, timesteps, encoder_hidden_states=text_embeddings)
    
    # 8. 计算 MSE 损失
    loss = F.mse_loss(noise_pred, noise)
    
    return loss
```

### 4.6 训练循环

```python
def train(self, all_latents, num_epochs, lr, output_dir, resume_from):
    # 展平所有 latent（不考虑类型）
    flat_data = [{'latent': latent, 'defect_type': dtype} 
                 for dtype, latents in all_latents.items()
                 for latent in latents]
    
    optimizer = torch.optim.AdamW(self.trainable_params, lr=lr, weight_decay=1e-2)
    
    for epoch in range(start_epoch, num_epochs):
        random.shuffle(flat_data)  # 每个 epoch 打乱
        
        for i in range(n):
            batch = merge_to_batch([flat_data[i]])  # batch_size = 1
            loss = self.train_step(batch)
            
            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(self.trainable_params, max_norm=1.0)
            optimizer.step()
        
        # 每个 epoch 保存 checkpoint
        self._save_checkpoint(checkpoint_path, optimizer, epoch, global_step)
```

**为什么 batch_size = 1**？
- LoRA 参数量很小（2.2M），batch_size=1 足够
- 降低显存需求
- 每个样本都能做一次参数更新

**为什么 weight_decay=1e-2**？
- L2 正则化，防止 LoRA 参数过大
- 过大的 LoRA 权重 = 过度偏离基座模型 = 过拟合

**为什么 clip_grad_norm_(max_norm=1.0)**？
- 裁剪梯度，防止单步异常梯度破坏训练
- 特别是早期训练时，噪声预测的梯度可能很大

## 5. 训练数据流

```
数据流（以一张图为例）:
═══════════════════════════════════════════

训练开始前（precompute_latents）:
  defect_merged/fg_class_4/xxx.png
      │
      ▼
  VAE Encoder
      │
      ▼
  latent = [4, 64, 64] (float32)  ← 保存到 cache.pt

训练过程中（train_step）:
  latent from cache
      │
      ├──▶ 随机噪声 ε ~ N(0, I)
      │
      ▼
  noisy_latent = √ᾱ_t × latent + √(1-ᾱ_t) × ε
      │
      ▼
  UNet Input = [noisy_latent(4ch), 0(1ch), 0(4ch)]  = 9ch
      │
      ▼
  UNet 预测噪声 ε_pred
      │
      ▼
  Loss = MSE(ε_pred, ε)  ← 让 UNet 学会"预测噪声"
      │
      ▼
  反向传播 → 更新 LoRA 参数
```

### 可视化训练过程

```
时间步 t=0 (原始图):
  latent  ← 几乎没有噪声

时间步 t=500 (半噪声):
  0.5×latent + 0.7×ε  ← 一半原图一半噪声

时间步 t=999 (几乎纯噪声):
  0.01×latent + 0.99×ε  ← 几乎全是噪声

UNet 的任务：
  给定 (noisy_latent, t, text_embedding)
  预测 → "当前噪声 ε 是什么"
  
  t 越小 → UNet 看原图细节 → 预测精细噪声
  t 越大 → UNet 看大致结构 → 预测粗粒度噪声
```

## 6. 损失函数与优化

### 6.1 损失函数

```python
loss = F.mse_loss(noise_pred, noise)
```

数学形式：

```
L = E_{x_0, ε, t} [ || ε_θ(x_t, t, text) - ε ||² ]

其中:
  x_0  = 原始 latent（来自 VAE 编码）
  ε    = 真实噪声 ~ N(0, I)
  t    = 均匀采样 [0, 1000)
  x_t  = √ᾱ_t × x_0 + √(1-ᾱ_t) × ε  (前向扩散)
  ε_θ  = UNet 预测的噪声（含 LoRA 参数 θ）
```

### 6.2 优化器配置

| 参数 | 值 | 作用 |
|------|-----|------|
| `lr` | 1e-4 | 学习率。LoRA 通常比全参数微调大 5-10 倍 |
| `weight_decay` | 1e-2 | L2 正则化，防止 LoRA rank 崩坏 |
| `betas` | (0.9, 0.999) | AdamW 默认动量参数 |
| `eps` | 1e-8 | AdamW 默认数值稳定项 |

### 6.3 梯度裁剪

```
梯度裁剪前:  ||g|| = 15.7  (异常梯度，可能破坏训练)
     │
     ▼
clip_grad_norm_(params, max_norm=1.0)
     │
     ▼
梯度裁剪后:  ||g|| = 1.0   (安全范围)

公式:
  if ||g|| > max_norm:
      g = g × max_norm / ||g||
```

## 8. 训练 vs 推理

### 8.1 核心区别

| | 训练 | 推理 |
|------|------|------|
| **输入** | 真实图片的 latent + 噪声 | 纯随机噪声 |
| **过程** | 加噪 → UNet 预测噪声 → MSE | UNet 逐歩去噪 → VAE 解码 |
| **UNet 参数** | 更新 LoRA（学习） | 冻结（使用） |
| **有无 Ground Truth** | 有（真实噪声 ε） | 无 |
| **Text Encoder** | 参与训练（LoRA 更新） | 冻结 |
| **输出** | 损失值 | 512×512 RGB 图像 |

### 8.2 数学对应

```
训练:      UNet(√ᾱ·x₀ + √(1-ᾱ)·ε, t, text) → 预测 ε
           让预测的 ε 接近真实的 ε
           → LoRA 学会"噪声对应什么纹理"

推理:      UNet(x_t, t, text) → 预测 ε
           x_{t-1} = 1/√α_t × (x_t - β_t/√(1-ᾱ_t) × ε)
           重复 T 步 → x_0
           → 从噪声中"提取"出缺陷纹理
```

### 8.3 训练时的特殊处理

```
为什么 mask 和 masked_image 填零？

训练时:
  UNet Input = [noisy_latent | 0 | 0]
               ↑ 实际信息    ↑ 无用

等效于:
  标准 UNet (4ch) 做扩散训练
  但因为我们用 Inpainting UNet + LoRA
  后续支持 Inpainting 推理

代价:
  5 个通道的计算浪费
  但 LoRA 权重兼容两种模式
```
