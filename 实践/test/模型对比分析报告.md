## 2. 模型详解

### 模型 1：DDPM（Denoising Diffusion Probabilistic Model）

**类型**：从零实现的扩散模型（无条件生成）

**简介**：经典的 Denoising Diffusion Probabilistic Model 实现，不依赖任何预训练权重，从零构建完整的 UNet 架构和扩散过程（前向加噪 + 逆向去噪）。是理解扩散模型原理的"教科书式"实现。

**技术路线**：
- **基座模型**：自定义 UNet，无预训练
- **扩散过程**：线性噪声调度（beta_1=1e-4 → beta_T=0.02），T=1000 步
- **时间嵌入**：Sinusoidal Position Embedding → Swish → Linear
- **UNet 结构**：通道倍增 [1,2,3,4]（128→256→384→512），第 2 层加入自注意力
- **训练目标**：MSE(预测噪声, 真实噪声)
- **优化器**：AdamW + CosineAnnealingLR + Warmup

**架构图**：

```
┌───────────────────────────────────────────────────────┐
│                   DDPM 训练流程                        │
│                                                       │
│  真实缺陷图 x_0                                        │
│      │                                                │
│      ▼                                                │
│  ┌────────────────────────────┐                       │
│  │   前向扩散 q(x_t \| x_0)   │  加高斯噪声 ε ~ N(0,I) │
│  │   x_t = √ᾱ_t x_0 + √(1-ᾱ_t) ε                     │
│  └────────────┬───────────────┘                       │
│               │                                       │
│               ▼                                       │
│         含噪图像 x_t                                   │
│               │                                       │
│  ┌────────────▼──────────────────────────────┐        │
│  │          自定义 UNet ε_θ(x_t, t)           │        │
│  │                                           │        │
│  │  Head (Conv 3→128)                        │        │
│  │  ┌──────────────────────────────────┐     │        │
│  │  │  TimeEmbedding (Sinusoidal)      │     │        │
│  │  └──────────────────────────────────┘     │        │
│  │  DownSample ×4 (ResBlock + Attn)          │        │
│  │      ch: 128 → 256 → 384 → 512            │        │
│  │  MiddleBlock (ResBlock + Attn)            │        │
│  │  UpSample ×4 (ResBlock + Skip)            │        │
│  │  Tail (GroupNorm → Swish → Conv)          │        │
│  └──────────────────────┬─────────────────────┘       │
│                         │                             │
│              ┌──────────▼──────────┐                  │
│              │  L = MSE(ε_θ, ε)    │                  │
│              └─────────────────────┘                  │
└───────────────────────────────────────────────────────┘

                           推理 (逆向过程)

             纯噪声 x_T ~ N(0,I)
                   │
                   ▼
          ┌──────────────────────────┐
          │  p_θ(x_{t-1} \| x_t) =   │  重复 T=1000 步
          │  N(x_{t-1}; μ_θ, σ_t²)   │
          │  μ_θ = 1/√α_t (x_t -     │
          │    (β_t/√(1-ᾱ_t)) ε_θ)   │
          └────────────┬─────────────┘
                       │
                       ▼
                 生成图像 x_0
```

**损失函数**：
```
L = MSE(ε_θ(x_t, t), ε)

其中:
  x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε    (前向扩散)
  ε_θ = UNet(x_t, t)                   (噪声预测)
```

**优点**：
- 代码完全透明，从零实现无依赖
- 完整的 UNet + TimeEmbedding + 扩散过程，教学价值高
- 支持自定义数据集和 CIFAR-10

**局限**：
- 分辨率仅 32×32，无法生成工业级高清图
- 推理需 1000 步，速度较慢
- 无条件生成，缺陷位置/类型不可控

**关键代码文件**：
- [Model.py](file:///d:/git/实践/4-28缺陷生成复现任务/DenoisingDiffusionProbabilityModel-ddpm-/Diffusion/Model.py) — 自定义 UNet
- [Diffusion.py](file:///d:/git/实践/4-28缺陷生成复现任务/DenoisingDiffusionProbabilityModel-ddpm-/Diffusion/Diffusion.py) — 训练器/采样器

### 模型 2：SD + LoRA（Stable Diffusion + Low-Rank Adaptation）

**类型**：基于预训练的扩散模型微调方法

**简介**：以 Stable Diffusion Inpainting 为基座模型，通过 LoRA 低秩适配技术微调 UNet 和 Text Encoder 的注意力层，使模型学会生成特定类型的工业缺陷纹理。训练时使用 DreamBooth 范式，通过 `<defect>` 占位词将缺陷图案绑定到文本概念。支持 txt2img（从纯噪声生成）和 img2img（参考图变异）双模式推理。

**技术路线**：
- **基座模型**：`runwayml/stable-diffusion-inpainting`（9 通道 UNet）
- **微调方式**：LoRA (rank=8)，目标层为 UNet 和 Text Encoder 的注意力投影层
- **可训练参数**：2,184,192（< 总参数 1%），冻结 VAE 和非注意力层
- **训练范式**：DreamBooth 风格，标准扩散训练（非 inpainting）
- **推理模式**：
  - txt2img：从纯随机噪声出发，CFG 引导去噪
  - img2img：参考图加噪后去噪变异
- **分辨率**：512×512

**损失函数**：

  W' = W + ΔW = W + A·B
  其中 A ∈ R^(d×r), B ∈ R^(r×k), r=8

**优点**：
- 512×512 高清输出，远超 DDPM（32×32）和 Pix2Pix（256×256）
- 双模式推理：txt2img 从零创造 + img2img 参考变异
- 参数效率极高：仅 218 万可训练参数（< 1%），低存储低成本
- Latent 预计算加速 130 倍，训练效率大幅提升

**局限**：
- 推理较慢（~5s/张）
- txt2img 模式下缺陷位置不可控（由随机种子决定）
- 基于 Inpainting UNet，txt2img 效果受限

### 模型 3：DefectFill（注意力引导缺陷填充）

**类型**：基于预训练的扩散模型微调 + 注意力监督方法

**简介**：与 SD+LoRA 使用同一个基座模型，但在训练时引入了额外的**注意力损失**。通过在 UNet 的解码器注意力层注册钩子（AttentionStoreProcessor），捕获交叉注意力图并与缺陷掩码对齐，从而强制模型在生成缺陷时将注意力集中在正确的区域。采用三部分损失联合优化策略。

**技术路线**：
- **基座模型**：`runwayml/stable-diffusion-inpainting` + LoRA
- **核心模块**：自定义 `AttentionStoreProcessor` 捕获 up_blocks 中的交叉注意力图
- **双路径训练**：
  - 真实缺陷掩码路径：学习缺陷语义
  - 随机矩形掩码路径：学习对象完整性
- **损失函数**：三部分联合

**架构图**：

```
┌──────────────────────────────────────────────────────────────────┐
│                    DefectFill 核心架构                              │
│                                                                    │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │            Stable Diffusion Inpainting (基座)                │   │
│  │  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │   │
│  │  │ Text Encoder │  │     UNet     │  │     VAE      │      │   │
│  │  │   + LoRA     │  │   + LoRA     │  │  (FROZEN)    │      │   │
│  │  └──────────────┘  └──────┬───────┘  └──────────────┘      │   │
│  │                           │                                  │   │
│  │     ┌─────────────────────▼──────────────────────┐          │   │
│  │     │    自定义 AttentionStoreProcessor            │          │   │
│  │     │                                             │          │   │
│  │     │  交叉注意力层 (attn2 in up_blocks):          │          │   │
│  │     │    Q = to_q(hidden_states)                  │          │   │
│  │     │    K = to_k(encoder_hidden_states)          │          │   │
│  │     │    V = to_v(encoder_hidden_states)          │          │   │
│  │     │                                             │          │   │
│  │     │  Attention = softmax(QK^T/√d)               │          │   │
│  │     │         │                                   │          │   │
│  │     │         ▼                                   │          │   │
│  │     │  [存储] → self.attention_maps[name]          │          │   │
│  │     │          → 计算 L_attn 损失                  │          │   │
│  │     └─────────────────────────────────────────────┘          │   │
│  └────────────────────────────────────────────────────────────┘   │
│                                                                    │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │                    三部分损失函数                              │   │
│  │                                                              │   │
│  │  L_def (λ=0.5):  缺陷区域加权 MSE                              │   │
│  │    weighted_loss = mask * (ε_pred - ε)^2                     │   │
│  │    L_def = Σ weighted_loss / Σ mask                          │   │
│  │                                                              │   │
│  │  L_obj (λ=0.2):  对象完整损失 (随机掩码修复)                     │   │
│  │    随机生成矩形掩码 → 学习修复不同位置/形状                       │   │
│  │                                                              │   │
│  │  L_attn (λ=0.05): 交叉注意力对齐损失                            │   │
│  │    avg_attn_map = mean(upsampled A^[V*])                     │   │
│  │    L_attn = MSE(avg_attn_map, defect_mask)                   │   │
│  │                                                              │   │
│  │  Total:  L = 0.5·L_def + 0.2·L_obj + 0.05·L_attn             │   │
│  └──────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────┘
```

**损失函数**：
```
L_total = λ₁·L_def + λ₂·L_obj + λ₃·L_attn

L_def  = Σ(mask · (ε_pred - ε)²) / Σ(mask)          λ₁=0.5
L_obj  = MSE(预测修复结果, 真实对象)                     λ₂=0.2
L_attn = MSE(avg(交叉注意力图), 缺陷掩码)                 λ₃=0.05
```

**优点**：
- 注意力引导确保缺陷生成位置准确
- 三损失联合优化，兼顾缺陷真实性 + 对象完整性 + 注意力对齐
- 支持 LPIPS 感知损失提升生成质量

**局限**：
- 训练更复杂（需同时优化 3 个损失）
- 推理速度较慢（~8s/张）
- 基于较老的 SD v1.5 Inpainting 版本

**训练命令**：
```bash
python train.py \
    --data_dir "./MVTec2" \
    --object_class bottle \
    --output_dir "./models/bottle" \
    --batch_size 2 \
    --max_train_steps 2000
```

### 模型 4：Pix2Pix（条件 GAN）

**类型**：基于训练的生成对抗网络方法（图像翻译）

**简介**：经典的 Pix2Pix 条件 GAN 模型，采用"图像翻译"的方式生成缺陷。输入一张正常产品图，Generator（UNet）输出对应的缺陷图，Discriminator（PatchGAN）判断生成结果的真假。两者通过对抗训练互相提升，训练 290 epoch，是项目中训练最充分、推理最快的模型。

**技术路线**：
- **生成器**：UNet（4 层编解码 + Skip Connection），输出 Tanh 激活
- **判别器**：PatchGAN（5 层卷积 + AdaptiveAvgPooling），输入为 [正常图, 缺陷图] 拼接
- **训练范式**：对抗训练（Generator vs Discriminator）
- **优化器**：Adam (lr=0.0002, β₁=0.5, β₂=0.999)
- **分辨率**：256×256
- **数据增强**：RandomHorizontalFlip + RandomVerticalFlip + RandomRotation(10°) + ColorJitter

**架构图**：

```
┌─────────────────────────────────────────────────────┐
│                    Pix2Pix 架构                        │

│  │        ▼                                 │        │
│  │  ┌────────────┐                          │        │
│  │  │ Enc1: Conv │ ──── 3→64 ── Skip ──┐   │        │
│  │  │    ↓ MaxPool    → 64×128×128     │   │        │

│  │  │ │ ┌────────┐                   ││   │        │

│  │  │ │ │ Conv   │     ↓ MaxPool     │   │        │
│  │  │ │ │ ┌──────┐                   │   │        │
│  │  │ │ │ │ Enc4 │ ── 256→512        │   │        │
│  │  │ │ │ │ Conv │     ↓ Bottleneck  │   │        │
│  │  │ │ │ │ ┌──────┐                │   │        │
│  │  │ │ │ │ │ Dec4 │ ← Concat[Enc3] │   │        │
│  │  │ │ │ │ │ ↑ Up │ → 512→256      │   │        │
│  │  │ │ │ │ │ ┌──────┐              │   │        │
│  │  │ │ │ │ │ │ Dec3 │ ← Concat[Enc2]│  │        │
│  │  │ │ │ │ │ │ ↑ Up │ → 512→128    │   │        │
│  │  │ │ │ │ │ │ ┌──────┐            │   │        │
│  │  │ │ │ │ │ │ │ Dec2 │ ← Concat[Enc1]│       │
│  │  │ │ │ │ │ │ │ ↑ Up │ → 256→64   │   │        │
│  │  │ │ │ │ │ │ │ ┌──────┐          │   │        │
│  │  │ │ │ │ │ │ │ │ Dec1 │ → 128→32 │   │        │
│  │  │ │ │ │ │ │ │ │ ┌──────┐        │   │        │
│  │  │ │ │ │ │ │ │ │ │ Final│ → 32→3 │   │        │
│  │  │ │ │ │ │ │ │ │ │ Tanh │        │   │        │
│  │  │ │ │ │ │ │ │ │ └──────┘        │   │        │
│  │  │ │ │ │ │ │ │ │      │          │   │        │
│  │  │ │ │ │ │ │ │ │      ▼          │   │        │
│  │  │ │ │ │ │ │ │ │ Output: 缺陷图  │   │        │
│  │  │ │ │ │ │ │ │ │ (3×256×256)     │   │        │
│  └──────────────────────────────────────────┘        │
│                                                       │
│  ┌──────────────────────────────────────────┐        │
│  │         Discriminator (PatchGAN)          │        │
│  │                                          │        │
│  │  Input: [正常图, 缺陷图] (6×256×256)     │        │
│  │        │                                 │        │
│  │        ▼                                 │        │
│  │  Conv(6→64, k=4, s=2) → LeakyReLU       │        │
│  │  Conv(64→128, k=4, s=2) → BN → LeakyReLU│        │
│  │  Conv(128→256, k=4, s=2) → BN → LeakyReLU       │
│  │  Conv(256→512, k=4, s=2) → BN → LeakyReLU       │
│  │  Conv(512→1, k=4) → AdaptiveAvgPool2d   │        │
│  │        │                                 │        │
│  │        ▼                                 │        │
│  │  Output: 真/假判断 (B×1)                  │        │
│  └──────────────────────────────────────────┘        │
│                                                       │
│  ┌──────────────────────────────────────────┐        │
│  │  损失:                                    │        │
│  │  L_G = GAN_loss(fake) + 10×L1(fake,real) │        │
│  │  L_D = 0.5×(GAN_loss(fake)+GAN_loss(real))│        │
│  └──────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────┘
```

**损失函数**：
```
L_G = BCE(D([x, G(x)]), 真) + 10 · L1(G(x), y)
L_D = 0.5 · [BCE(D([x, G(x)]), 假) + BCE(D([x, y]), 真)]
```

**优点**：
- **推理极快**：<0.5s/张，适合实时应用
- **可控性最强**：输入-输出一一对应，缺陷位置完全可控
- **训练最充分**：290 epoch，30 个 checkpoint
- **数据增强丰富**：Flip + Rotation + ColorJitter

**局限**：
- 分辨率 256×256，不如 SD 系列的 512×512
- 多样性较差（输入固定则输出固定）
- 需要配对数据（正常图 + 对应缺陷图）
- 无预训练，从零训练

**训练命令**：
```bash
python train.py
```

**推理命令**：
```bash
python inference.py
```

### 4.3 各模型优势总结

**SD+LoRA (test/)**
- 512×512 高清输出，远超其他模型
- 双模式推理：txt2img（从零创造）+ img2img（参考变异），灵活度最高
- 多类型支持：6 种缺陷类型独立生成
- 参数效率：仅 218 万可训练参数（< 1%），便于存储和部署

**Pix2Pix**
- 推理最快：<0.5s/张，适合实时应用
- 可控性最强：输入-输出一一对应，缺陷位置完全可控
- 训练最充分：290 epoch，30 个 checkpoint
- 数据增强：Horizontal/Vertical Flip + Rotation(10°) + ColorJitter

**DefectFill**
- 注意力引导：L_attn 确保缺陷区域生成一致
- 多目标训练：缺陷 + 对象 + 注意力三联合
- LPIPS 感知：VGG 感知损失提升生成质量

**DDPM**
- 代码完全透明，从零实现，高教育价值
- 支持自定义数据集和 CIFAR-10

## 6. 总结与建议

### 6.1 模型推荐（按场景）

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| **数据增强（需要多样性）** | **SD+LoRA (test)** | txt2img 从零生成，多样性最强 |
| **数据增强（需要可控）** | Pix2Pix | 输入控制输出，位置/形状可控 |
| **缺陷修复/填充** | DefectFill | 注意力引导 + Inpainting |
| **快速原型验证** | DDPM | 代码简洁，从零实现，教育价值高 |

### 6.2 SD+LoRA (test) 后续改进方向

1. **继续训练**：当前仅 6 epoch，建议训到 20+ epoch
2. **迁移到标准 SD Pipeline**：当前基于 Inpainting UNet，txt2img 效果受限
3. **数据均衡**：type 0 仅 6.6%，考虑 oversampling
4. **引入 FID/IS 评估**：量化生成质量
5. **缺陷类型命名**：与实际业务对齐
