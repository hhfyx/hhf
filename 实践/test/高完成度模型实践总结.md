## 1. 模型选择与对比总览

### 1.1 为什么选这 3 个

| 模型 | 选择理由 | 完成度 |
|------|---------|--------|
| **SD+LoRA** | 主攻模型，数据预处理→训练→双模式推理全链路完成 | ⭐⭐⭐⭐⭐ |
| **Pix2Pix** | 训练最充分（290 epoch），推理最快（<0.5s/张），输出最多（50+张） | ⭐⭐⭐⭐⭐ |
| **DefectFill** | 注意力引导创新方法，三损失联合优化 | ⭐⭐⭐⭐ |

### 1.2 三句话速览

| 模型 | 一句话 |
|------|--------|
| **SD+LoRA** | 用 Stable Diffusion 大师 + LoRA 极低成本微调，从纯噪声生成 512×512 高清缺陷图 |
| **Pix2Pix** | 输入正常图→输出缺陷图，像翻译一样直接，0.5 秒出图，位置完全可控 |
| **DefectFill** | 在 SD+LoRA 基础上眼睛盯着缺陷位置画，注意力损失确保缺陷生成在正确区域 |

#### 核心代码

```python
# train_defect_generator.py
class DefectGeneratorTrainer:
    def __init__(self, model_id, device="cuda", lora_rank=8):
        # 1. 加载基座模型
        self.pipe = StableDiffusionInpaintPipeline.from_pretrained(
            model_id, torch_dtype=torch.float16, safety_checker=None
        ).to(device)

        # 2. 配置 LoRA - UNet
        unet_lora_config = LoraConfig(
            r=lora_rank,
            lora_alpha=lora_rank,
            target_modules=["to_k", "to_q", "to_v", "to_out.0"],
            lora_dropout=0.1,
        )
        self.pipe.unet = get_peft_model(self.pipe.unet, unet_lora_config)

        # 3. 配置 LoRA - Text Encoder
        text_lora_config = LoraConfig(
            r=lora_rank,
            target_modules=["k_proj", "q_proj", "v_proj", "out_proj"],
        )
        self.pipe.text_encoder = get_peft_model(
            self.pipe.text_encoder, text_lora_config
        )

        # 4. 冻结 VAE
        self.pipe.vae.requires_grad_(False)

        # 5. 可训练参数统计: 仅 2,184,192 个 (< 1%)
        trainable_params = sum(p.numel() for p in self.pipe.unet.parameters() if p.requires_grad)
        # 约 218 万

    def train_step(self, latents, timestep, text_embeddings):
        # 标准扩散训练
        noise = torch.randn_like(latents)
        noisy_latents = self.scheduler.add_noise(latents, noise, timestep)

        # Inpainting UNet 需要 9 通道: [noisy, mask, masked_image]
        mask = torch.zeros_like(latents[:, :1, :, :])  # 填零
        masked_latents = torch.zeros_like(latents)     # 填零
        model_input = torch.cat([noisy_latents, mask, masked_latents], dim=1)

        noise_pred = self.pipe.unet(model_input, timestep, text_embeddings).sample

        loss = F.mse_loss(noise_pred.float(), noise.float())
        return loss
```

#### 关键训练策略

| 策略 | 说明 | 效果 |
|------|------|------|
| **Latent 预计算** | 训练前将所有图片通过 VAE 编码为 latent 缓存 | 39s/step → 0.31s/step (130×) |
| **Gradient Checkpointing** | 训练 UNet 时启用 | 节省 ~40% 显存 |
| **梯度裁剪** | max_norm=1.0 | 防异常梯度破坏训练 |

#### 核心代码

```python
# train.py
class UNetGenerator(nn.Module):
    """生成器：UNet 4层编解码 + Skip Connection"""
    def __init__(self):
        super().__init__()

        def conv_block(in_ch, out_ch):
            return nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 3, padding=1),
                nn.BatchNorm2d(out_ch),
                nn.ReLU(inplace=True),
                nn.Conv2d(out_ch, out_ch, 3, padding=1),
                nn.BatchNorm2d(out_ch),
                nn.ReLU(inplace=True)
            )

        # Encoder
        self.enc1 = conv_block(3, 64)
        self.enc2 = conv_block(64, 128)
        self.enc3 = conv_block(128, 256)
        self.enc4 = conv_block(256, 512)
        self.pool = nn.MaxPool2d(2)

        # Decoder (带 Skip Connection)
        self.dec4 = conv_block(512, 256)
        self.dec3 = conv_block(256 * 2, 128)    # Concat enc3
        self.dec2 = conv_block(128 * 2, 64)     # Concat enc2
        self.dec1 = conv_block(64 * 2, 32)      # Concat enc1

        self.up4 = nn.ConvTranspose2d(256, 256, 2, stride=2)
        self.up3 = nn.ConvTranspose2d(128, 128, 2, stride=2)
        self.up2 = nn.ConvTranspose2d(64, 64, 2, stride=2)
        self.final = nn.Conv2d(32, 3, 1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))

        d4 = self.dec4(e4)
        d4 = self.up4(d4)
        d3 = self.dec3(torch.cat([d4, e3], dim=1))
        d3 = self.up3(d3)
        d2 = self.dec2(torch.cat([d3, e2], dim=1))
        d2 = self.up2(d2)
        d1 = self.dec1(torch.cat([d2, e1], dim=1))

        return torch.tanh(self.final(d1))


class Discriminator(nn.Module):
    """PatchGAN 判别器"""
    def __init__(self):
        super().__init__()

        def disc_block(in_ch, out_ch):
            return nn.Sequential(
                nn.Conv2d(in_ch, out_ch, 4, stride=2, padding=1),
                nn.BatchNorm2d(out_ch),
                nn.LeakyReLU(0.2, inplace=True)
            )

        self.model = nn.Sequential(
            nn.Conv2d(6, 64, 4, stride=2, padding=1),
            nn.LeakyReLU(0.2, inplace=True),
            disc_block(64, 128),
            disc_block(128, 256),
            disc_block(256, 512),
            nn.Conv2d(512, 1, 4, padding=1),
            nn.AdaptiveAvgPool2d(1)
        )

    def forward(self, xy):
        return self.model(xy).view(xy.size(0), -1)
```

```python
# model.py - 注意力处理器
class AttentionStoreProcessor(AttnProcessor):
    """捕获交叉注意力图，用于计算 L_attn 损失"""
    def __call__(self, attn, hidden_states, encoder_hidden_states=None, ...):
        query = attn.to_q(hidden_states)
        key = attn.to_k(encoder_hidden_states)
        value = attn.to_v(encoder_hidden_states)

        # 计算注意力分数
        attention_scores = torch.matmul(query, key.transpose(-1, -2))
        attention_scores = attention_scores * attn.scale
        attention_probs = F.softmax(attention_scores, dim=-1)

        # 存储到模型实例（仅 up_blocks 的交叉注意力层）
        if "up_blocks" in name and "attn2" in name:
            self.model.attention_maps[name] = reshaped_probs.detach()

        return torch.matmul(attention_probs, value)

# 注意力损失计算
def get_attention_loss(self, masks):
    loss = 0
    for name, attn_map in self.attention_maps.items():
        # 取缺陷文本 token 的注意力
        defect_attn = attn_map[:, :, :, defect_token_idx]
        # 上采样到 mask 尺寸
        resized = F.interpolate(defect_attn, size=masks.shape[-2:], mode='bilinear')
        # 平均所有注意力头
        avg_attn = resized.mean(dim=1)
        loss += F.mse_loss(avg_attn, masks)
    return loss / len(self.attention_maps)
```

```
阶段 1 — 数据准备（约 2 小时）

阶段 3 — 训练优化（约 2 小时）

├─ 支持断点续训 --resume_from
├─ V1 训练 1806 张 2 epoch (loss=0.158)
```

### 7.4 常见问题解决

| 问题 | 原因 | 解决 |
|------|------|------|
| **HF 模型下载超时** | 国内网络 | `set HF_ENDPOINT=https://hf-mirror.com` |
| **NaN loss** | 梯度爆炸 | 梯度裁剪 (max_norm=1.0) + loss clamp |
| **OOM 显存不足** | batch 太大 | 减小 batch_size 或启用 Gradient Checkpointing |
| **中文路径乱码** | OpenCV 不支持中文 | 使用 `imread_unicode` (PIL 方案) |
| **CUDA 类型不匹配** | FP16/FP32 混用 | 统一 `.half()` 或 `.float()` |
| **训练/推理慢** | 未预计算 latent | 启用 Latent 预计算缓存 |
| **img2img 效果差** | strength 过低 | 提高到 0.85-0.95 |
